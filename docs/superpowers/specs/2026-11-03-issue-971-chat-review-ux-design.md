# 이슈 #971 채팅·거래 완료·후기 사용성 개선 설계

- 이슈: https://github.com/TEAM-ROMROM/RomRom-FE/issues/971
- 범위: 클라이언트만. 서버 변경 필요 항목(메시지 삭제, 방별 알림 끄기, 서버 필터, 약속 카드)은 제외
- 원칙: 판정 로직은 순수 함수(`lib/utils/*_rules.dart`)로 빼서 단위 테스트, 화면은 호출만

## 채팅방

### 1. 전송 실패 표시·다시 보내기
- 문제: `sendMessage`가 미연결 시 예외를 던지지만 잡지 않음. 낙관적 말풍선은 성공처럼 남고 입력창은 비워짐. 10초 타이머는 스낵바만 띄움
- 변경
  - 전송 상태 enum `ChatMessageSendStatus { sent, sending, failed }` (`lib/enums/`), 판정 순수 함수 `resolveMessageSendStatus`
  - 텍스트: 소켓 전송을 먼저 시도 > 즉시 실패면 말풍선 없이 입력 글 유지 + 스낵바. 성공 시에만 말풍선 삽입·입력창 비움
  - 사진·위치: 즉시 실패면 실패 말풍선으로 삽입 (업로드한 사진을 다시 고르지 않게)
  - 메시지별 10초 타이머 > 서버 에코 없으면 실패 표시
  - 실패 말풍선 옆 `다시 보내기`·`삭제`. 다시 보내기는 새 로컬 ID·시각으로 맨 아래에 재삽입, 원래 메시지는 '대체됨' 목록에 보관 > 늦게 온 원래 에코는 흡수해 화면에 하나만 남김
  - 텍스트 전송 잠금(`_isSendingMessage`)은 필드가 아니라 '실패 아닌 대기 텍스트가 남았는지'로 매번 계산 (`hasPendingTextAwaitingEcho`) > 재연결 확정·중복 에코·늦은 에코 어느 경로에서도 잠김 누락 없음
  - 에코 짝짓기 (`lib/utils/chat_message_send_rules.dart`): 시각은 로컬 전송 시각 <-> 에코 수신 시각(1분 이내, 서버 시계 무관). 텍스트는 내용, 사진은 주소 집합, 위치는 위경도로 비교하고 값이 없을 때만 같은 종류 중 가장 오래된 것과 짝지음
  - 재연결 동기화 시 서버에 이미 저장된 내 로컬 메시지는 정리 (`findPendingLocalIdsConfirmedByServer`, 이미 화면에 표시된 서버 메시지는 후보 제외)
- 테스트: 상태 판정, 에코 짝짓기(시각·사진·위치), 재조회 확정(표시된 메시지 제외), 전송 잠금, 에코 처리 결정(`resolveIncomingEcho`), 에코 병합 시 위치 좌표 보존

### 2. 이전 메시지 페이징
- 문제: 진입 시 page 0, 50건만 조회
- 변경: 목록 맨 위(역순 목록 maxScrollExtent) 근처 도달 시 다음 페이지 조회 (`pageNumber`·`pageSize`, 응답 `last`로 끝 판정). 이미 있는 ID는 제외하고 뒤(오래된 쪽)에 붙임 > 역순 목록이라 스크롤 위치 유지. 조회 중 목록 맨 위 로딩 표시, 실패 시 자동 조회를 멈추고 목록 맨 위에 '다시 불러오기' 행
- 테스트: `appendOlderMessages` 중복 제거·순서 유지

### 3. 위치 전송 실패 처리
- 변경: 위치도 낙관적 말풍선 + 1과 같은 실패 처리. 좌표 없음은 스낵바 안내
- 에코 병합 함수가 위도·경도를 버리던 문제도 함께 보정

### 4. 완료 요청 카드 중복
- 문제: 낙관적 요청 카드 ID(`_latestLocalTradeRequestId`)가 요청 흐름에서 설정되지 않고 사진 전송이 엉뚱하게 덮어씀 > 에코 도착 시 로컬 카드 제거 실패
- 변경: 요청 성공 시 `local_trade_request_{시각}` ID 생성·보관, 사진 전송의 잘못된 대입 제거

### 5. 완료 요청 카드 문구
- 변경: '미리 작성한 후기가 전달됩니다' > '상대방이 확인하면 교환이 완료되고 서로 후기를 남길 수 있어요.'

### 6. 메시지 복사
- 문제: `SelectableLinkify`가 `contextMenuBuilder`를 null로 넘겨 길게 눌러도 메뉴 없음 (flutter_linkify 6.0.0)
- 변경: 기본 선택 메뉴(`AdaptiveTextSelectionToolbar.editableText`) 지정

### 7. 위치 선택 폴백 안내
- 변경: 권한 거부·현재 위치 실패 시 서울시청 기준 안내 스낵바

### 8. 사진 전송 시 입력 글 유지
- 문제: 입력 글이 사진 메시지 content로 전송되고 입력창이 비워짐 (사진 말풍선은 content 미표시라 글이 사라짐)
- 변경: 사진 메시지 content는 고정 문구, 입력창은 건드리지 않음

## 채팅 목록·탭바

### 9. 모르는 방 메시지
- 실제 동작: 메시지는 구독한 방에서만 옴. 모르는 방 메시지는 새로고침으로 목록에서 밀려났지만 구독은 남은 방 등에서 옴. 상대가 새로 만든 방은 구독 전이라 이 경로로 오지 않음
- 변경: 목록에 없는 방 메시지 > 첫 페이지 병합 재조회(`refreshFirstPage`, 동시 1회). 재조회 후에도 없는 방(나간 방·차단 방)은 기록해 이후 무시(전체 새로고침 시 초기화). 상대가 새로 만든 방은 채팅 탭 전환 시 첫 페이지 병합 재조회가 보정
- 테스트: 연속 수신 재조회 1회, 재조회 후에도 없는 방 재조회 안 함, 병합 시 이후 페이지·페이징 유지, 실패 시 목록 유지

### 10. 탭바 안 읽음 배지
- 탭 전환 재조회는 0페이지를 기존 목록에 병합(`mergeFirstPageRooms`) > 2페이지 이후 유지
- 변경: `ChatRoomsState.hasUnreadMessages` 파생값, `CustomBottomNavigationBar`를 Consumer로 바꿔 채팅 탭 아이콘에 점 표시 (`main_screen.dart` 무변경)
- 보정: 채팅방 안에서 받은 메시지가 목록 안 읽음 수를 올리던 문제 > 채팅방 진입·퇴장 시 해당 방 읽음 처리
- 테스트: 파생값

### 11. 필터 결과 부족
- 변경: 필터 탭 전환 시에도 자동 이어 불러오기 실행. 필터 결과가 비었는데 다음 페이지가 있으면 '더 불러오기' 버튼 표시

### 12. 다음 페이지 실패
- 변경: `loadMore` 실패 시 목록 유지 + 예외 전달 > 화면이 스낵바
- 테스트: 실패 시 예외·목록 유지

## 거래 완료·후기

### 13. 상대 선택 실패·탈퇴 표시
- 변경: 조회 실패 > `EmptyStateView.error`(다시 시도). 탈퇴 상대 > '(탈퇴)' 표시·탈퇴 아바타·선택 불가

### 14. 앱 밖 교환 완료
- 확인: 물품 상태 변경 API(`myItemsProvider.changeStatus`)가 채팅 상대 없이 교환완료로 바꿀 수 있음 (등록 탭 `_toggleItemStatus`가 이미 사용)
- 변경: 상대 선택 화면에 '채팅 없이 교환했어요' > 확인 모달 > 결과 반환. 등록 탭 해당 블록에서 상태 변경 호출
- 반환 타입: `TradeCompletePartnerSelection`(채팅방 ID 또는 앱 밖 교환)

### 15. 완료 카드 후기 쓰기
- 확인: 후기 작성 여부를 알 수 있는 기존 응답 필드 없음
- 변경: 교환 완료 카드에 '후기 쓰기' 버튼 > `TradeReviewScreen`. 이번 진입에서 작성 성공하면 숨김. 이미 작성한 경우는 서버 오류 문구를 에러 모달로 안내(기존 처리)
- 후기 화면 '열림' 가드: 확인 API 성공과 소켓 완료 메시지가 둘 다 열려 할 때, 버튼 연타 때 1개만 (닫히면 해제)

### 16~19. 후기 화면
- 평가별 태그: '별로예요'는 칭찬 태그 숨김, 제목 '어떤 점이 아쉬웠나요?'. 서버 태그가 칭찬 5종뿐이라 부정 태그는 추가하지 않음
- 한마디만 제출: 태그 또는 한마디 중 하나만 있어도 '완료' 가능
- 건너뛰기: 쓴 내용이 있으면 확인 모달 후 버림
- 원래 화면 복귀: 메인 초기화 대신 `pop(true)`
- 글자 수: 200자 제한 + 카운터 (서버 제한 미확인 > 보수적 값)
- 테스트: `trade_review_rules.dart` (평가별 태그, 제출 가능, 제출 값 정리)
